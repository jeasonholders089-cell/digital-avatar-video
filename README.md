# 数字人口播视频 Skill

这是一个 Codex Skill，用于基于本人数字分身和已确认的本人声音制作连续口播视频，并完成字幕生成与音画质量检查。

## 安装

将本仓库克隆到 Codex Skills 目录，或把仓库内容放入：

```text
.agents/skills/digital-avatar-video/
```

Skill 入口为根目录的 `SKILL.md`。完整教程、HeyGen 请求示例和质检清单见 `references/tutorial.md`。

## 处理原则

- 以同一份最终音频作为口型和字幕的时间轴。
- 长口播优先一次连续渲染，不循环短动作片段或拼接多个任务。
- 付费任务提交前检查余额并使用稳定幂等键；结果不明时禁止盲目重试。
- 保留无字幕母版，并对口型观感进行人工播放复核。

该 Skill 不包含 API Key、个人数字分身标识或账户状态。HeyGen API 参数和产品能力可能变化，执行时以官方文档为准。
